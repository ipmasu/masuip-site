# 新域名 + 公司电脑自建服务器方案

## 结论

可以做，但不建议把公司电脑直接暴露为唯一公网服务器。

更稳的推荐方案是：

**公司电脑作为源站 + Cloudflare Tunnel / FRP / 云服务器反向代理作为公网入口。**

这样可以减少固定公网 IP、路由器端口映射、80/443 端口被封、安全暴露、证书续期等问题。

## 两种路线

### 路线 A：公司电脑直接做公网服务器

需要条件：

- 公司宽带有公网 IP，最好是固定公网 IP
- 运营商允许开放 80 和 443 端口
- 路由器可以做端口映射
- 公司电脑长期在线
- 有 UPS 或稳定电源
- Windows 防火墙只开放必要端口
- 使用 HTTPS 证书
- 定期备份和安全更新

优点：

- 服务器完全在自己公司
- 不需要额外云服务器

缺点：

- 办公宽带经常没有固定公网 IP
- 80/443 端口可能被运营商限制
- 停电、电脑重启、网络断线都会导致网站不可访问
- 公网暴露公司电脑有安全风险
- 如果服务器在中国内地面向公网提供网站服务，通常需要处理ICP备案/接入要求

### 路线 B：公司电脑做源站，公网入口放在云端

推荐。

可选入口：

- Cloudflare Tunnel
- 一台轻量云服务器 + Nginx 反向代理
- FRP 内网穿透
- Zero Trust/Tunnel 类服务

优点：

- 公司电脑不直接暴露公网端口
- 不一定需要固定公网 IP
- HTTPS 和访问入口更容易管理
- 可以用云端入口做缓存、防护和访问控制

缺点：

- 需要维护一个云端入口或隧道服务
- 访问速度取决于隧道/云端质量
- 如果面向中国内地用户，还要考虑备案和访问速度

## 域名建议

如果重新注册新域名，可以考虑：

- `masu-ip.com`
- `masuinnovation.com`
- `xinrui-ip.com`
- `xruip.com`
- `patentmapinnovation.com`
- `chinaipstrategy.com`

选择原则：

- 面向国际客户，优先英文短域名
- 不要太长
- 能体现 Ma Su、China IP、patent map、innovation strategy
- 如果要重点做个人品牌，可优先 Ma Su
- 如果要重点做机构品牌，可优先 ShineRed IP

## 公司电脑要求

- 建议使用一台专门电脑，不要用日常办公主力机
- Windows 10/11 Pro 或 Windows Server 更好
- 固态硬盘
- 8GB+ 内存
- 自动开机或断电恢复
- 禁止随意安装软件
- 单独创建网站目录，例如 `C:\Websites\masuip`
- 每周备份网站目录

## 推荐 Web Server

推荐使用 Caddy：

- 配置简单
- 静态网站友好
- 支持自动 HTTPS
- Windows 可用

如果使用 Cloudflare Tunnel 或内网反代，也可以只让 Caddy 监听本机端口，例如 `localhost:8080`。

## 备案与合规提醒

如果网站服务器实际接入在中国内地，并面向公网提供服务，通常需要按接入商要求完成 ICP 备案。不同接入方式、域名注册地、服务器所在地、访问入口所在地会影响具体流程。

正式上线前应让域名注册商、接入商或服务器维护方确认：

- 新域名是否需要 ICP 备案
- 备案主体用公司还是个人
- 是否需要公安备案
- 当前办公室宽带是否允许对外提供网站服务
- 80/443 端口是否可开放

## 推荐落地顺序

1. 先确定新域名
2. 确定是直接公网服务器还是隧道/云入口
3. 在公司电脑部署静态站
4. 内网访问测试
5. 外网访问测试
6. 配置 HTTPS
7. 配置备份
8. 做安全加固
9. 上线前合规确认
10. 正式切换 DNS
